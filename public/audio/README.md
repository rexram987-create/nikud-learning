# שמע
קובצי MP3 של שמות הסימנים ומילות הדוגמה, שנוצרו בסינתזת קול בקול he-IL-HilaNeural. אלה אינם הקלטות של קריין אנושי. Manifest ממפה מזהי פריטים לקבצים. יש לבדוק את הגיית כל קובץ לפני שימוש לימודי מחייב; בפרט שווא ומפיק עשויים להיקרא בהגייה הישראלית הרגילה. אין להוסיף קבצים מצד שלישי ללא הרשאה מתאימה.
