# לומדים ניקוד
יישומון PWA בעברית ללימוד ניקוד: ארבעה שיעורים, הסברים, מילים לדוגמה, תרגול בהקשר ומעבדת ניקוד.

## הפעלה
האתר סטטי. מקומית: `python3 -m http.server 8080`, ואז פתחו `http://localhost:8080`.
בדיקות: `npm test`.
פריסה ב-Vercel: Framework Preset = Other, ללא Build Command ו-Output Directory = `.`.

## התקנה ושימוש ללא אינטרנט
ב-Chrome בנייד לחצו על כפתור ההתקנה או השתמשו בתפריט הדפדפן. המתינו לחיווי שהתוכן זמין ללא אינטרנט. בהתקנה הראשונית יורדים גם קובצי השמע. ההתקדמות נשמרת ב-localStorage במכשיר, ללא חשבון.

## שמע
קובצי MP3 מסונתזים בעברית ב-public/audio, עם מיפוי ב-manifest.json. כל סימן ושלוש מילות הדוגמה שלו מקבלים קובץ נפרד. אם קובץ נכשל, ננסה הקראה של המכשיר רק אם קיים בו קול עברי ונציג שזהו מצב הקראה. ללא קול זמין תופיע הודעה מפורשת. אין השמעת צירופים שרירותיים במעבדה.

## תוכן
ההסברים מבדילים בין סיווג דקדוקי ובין הגייה ישראלית. שווא נע, שווא נח ומפיק נבחנים בתוך מילים. חטפים ומפיק מוגבלים במעבדה לאותיות מתאימות. החומר אינו קורס מלא בכללי הניקוד.

## קבצים
src/lessons.js — תוכן ושאלות; src/app.js — ממשק ותרגול; src/audio.js — השמעה; src/progress.js — התקדמות; src/install.js — התקנה ועדכון; sw.js — מטמון בגרסאות. סמלי PNG ב-icons. אין מפתחות סודיים או שרת.

## עדכון
שנו את VERSION ב-sw.js כשמשנים תוכן או שמע. גרסה חדשה מציעה כפתור עדכון; ההתקדמות אינה נמחקת.
